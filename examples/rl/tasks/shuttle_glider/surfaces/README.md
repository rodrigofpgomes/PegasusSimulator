# ShuttleGlider with active surfaces

[`curriculum/`](curriculum/README.md) contains the selected eight-action
experiments. Each policy commands the four lift rotors, puller, elevator,
aileron and rudder. Each environment defines its own reward terms; the task
folders use the shared RL reset manager supplied by the training launcher.
No no-curriculum surface-control task has yet been selected;
that comparison remains a separate experiment to implement.
